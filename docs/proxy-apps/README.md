# 电脑上的代理软件与 VPN 分流共存

路由器上的 L2TP/IPsec 插件按「域名规则」分流时，靠的是电脑把 DNS 查询发给路由器：路由器看到查询，向 VPN 那边的 DNS 要到内网地址，同时把这个地址的路由加到 VPN。电脑上开着 Clash、Surge 一类代理软件时，下面三种情况会让这套机制失效：

1. **虚假 IP（fake-ip）**：代理软件截下发往外部 DNS 的查询，返回自己的虚假地址。路由器看不到查询，也就不会加 VPN 路由。
2. **TUN 模式**：代理软件接管电脑上大部分 IPv4 路由，内网网段也可能在里面，内网流量会被转到代理节点。
3. **系统代理**：浏览器把请求交给代理软件，由代理软件自己解析域名、决定出口，路由器的分流根本用不上。

所以要在代理软件里做四件事：

| # | 要做的 | 解决的问题 |
| --- | --- | --- |
| 1 | 内网域名不用虚假 IP | 1 |
| 2 | 内网域名交给路由器解析 | 1、3 |
| 3 | 内网域名和内网网段直连 | 2、3 |
| 4 | 系统代理忽略内网域名和内网网段 | 3 |

## 占位符

下文和 [mihomo.yaml](mihomo.yaml) 里的占位符换成实际值：

| 占位符 | 填什么 |
| --- | --- |
| `<内网域名后缀>` | 和插件「域名后缀」规则一致，不带开头的点 |
| `<内网网段>` | 和插件「指定网段」规则一致，CIDR 写法 |
| `<路由器地址>` | 路由器的 LAN 地址，也就是电脑网络设置里的 DNS 服务器 |
| `<内网域名>` | 用来测试的一个完整内网域名 |

有多个后缀或网段时，每个写一行。

## Clash / mihomo

把 [mihomo.yaml](mihomo.yaml) 里的内容**合并**到现有配置对应的段落里，不要整段覆盖。规则要放在其他规则前面，尤其是 `GEOIP` 和 `MATCH` 之前。

用图形界面的规则编辑器时：

| 字段 | 域名规则 | 网段规则 |
| --- | --- | --- |
| 类型 | `DOMAIN-SUFFIX` | `IP-CIDR` |
| 内容 | `<内网域名后缀>` | `<内网网段>` |
| 策略 | `DIRECT` | `DIRECT` |
| 不解析主机名（`no-resolve`） | — | **开** |
| 匹配来源 IP（`src`） | — | **关** |

- **不解析主机名**：连接目标是域名时，不为了判断这条网段规则去查 DNS，直接跳过。
- **这条网段规则管两种情况**：直接用 IP 访问；以及开着 TUN 模式时，终端里的 curl、ssh 等不走系统代理的程序先解析出内网地址再连接，代理软件在 TUN 里只看到 IP，域名规则匹配不上。只用系统代理、不开 TUN 时可以不加。
- **匹配来源 IP**：拿发起连接的设备地址去比，不是拿要访问的地址去比。开了这条规则就永远不会生效。

## Surge 等其他软件

找到对应的四个设置即可：虚假 IP 例外（fake-ip filter / always-real-ip）、按域名指定 DNS 服务器、直连规则、系统代理例外（skip-proxy / bypass）。网段规则同样要选「不解析」。

## 系统代理例外（macOS）

系统设置 → 网络 → 当前网络的「详细信息」→ 代理 → 「忽略这些主机与域的代理设置」，加上：

```text
*.<内网域名后缀>, <内网网段>
```

有些代理软件每次启动会重写系统代理设置，这时要在代理软件自己的「系统代理绕过」设置里加。

浏览器开了「安全 DNS」（DoH）时，也会绕过路由器，需要关掉，或者把内网域名加入例外。

## 检查是否生效

在电脑上依次执行：

```bash
scutil --dns | grep nameserver | sort -u
```
应该只有 `<路由器地址>`。

```bash
dig +short <内网域名>
```
应该是内网地址，和 `dig +short <内网域名> @<路由器地址>` 的结果一样，不能是代理软件的虚假 IP。

```bash
curl -m 8 -sk -o /dev/null -w '%{http_code}\n' https://<内网域名>
```
返回 HTTP 状态码（200、302、401、403 等都说明网络通了），不能是 `000`。

最后用浏览器打开，确认走系统代理时也能访问。

在路由器上执行 `ip -4 route show table 41717`，应该能看到刚才解析出的内网地址，出口是 `l2tp-vpn`。
